Built

Two things I made rather than tested

DropIt

Automatic video optimisation for the web

Source not yet published

  • Laravel 13
  • PHP 8.3
  • Angular 18
  • MySQL 8
  • FFmpeg
  • SSE

Upload a video, get a smaller file back with no visible quality loss.

Encoding is slow, so nothing happens in the request. The upload dispatches a queued job and the browser follows along over server-sent events. The part I care about most is the decision in the middle: the resolver reads what the file actually is before choosing how to treat it, and when a file is already well encoded it skips the work rather than re-encoding it for nothing.

01

Analyse

FFprobe reads codec, resolution, bitrate, duration and audio track.

02

Resolve

Strategy picks codec, CRF, preset and a bitrate cap from that metadata. H.264 below 4K, H.265 above. Already optimised means skip.

03

Encode

FFmpeg re-encodes, progress streams to the browser, result shows original against optimised size.

Laid out in layers so the encoding logic never touches HTTP: use cases and DTOs in the application layer, entities and value objects in the domain, FFmpeg and the queue behind interfaces in infrastructure. Controllers stay thin enough to be uninteresting, which is the point.
